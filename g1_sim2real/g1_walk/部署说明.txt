三、输入输出约定
模型：LSTM(47,64)，1 层；Actor 为 64→32→12，ELU。
47 维单帧观测（内部 LSTM 保存历史，不是拼接六帧）：
0:3    骨盆角速度 ×0.25
3:6    骨盆坐标系投影重力，四元数 wxyz，直立时约 [0,0,-1]
6:9    [vx,vy,yaw_rate] ×[2,2,0.25]
9:21   双腿关节角减默认角度
21:33  双腿关节速度 ×0.05
33:45  上一步策略动作
45:47  sin/cos 相位，周期 0.8 秒
动作：12 维；目标角=默认角+0.25×动作。
每条腿关节顺序：hip_pitch, hip_roll, hip_yaw, knee, ankle_pitch, ankle_roll。
SDK 电机索引：左腿 0–5，右腿 6–11。
每条腿默认角度：[-0.1,0,0,0.3,-0.2,0]。
每条腿 kp=[100,100,100,150,40,40]，kd=[2,2,2,4,2,2]。
训练 dt=0.005、decimation=4；策略周期 0.02 秒（50 Hz）。
训练模型为 g1_12dof.urdf；腰、双臂在训练模型中固定。
实机配置面向 G1 29 电机：hg 消息，pelvis IMU，PR 模式；腰、双臂 12–28 共 17 个电机固定到配置目标（默认全零），不是由这个策略控制。
此策略与本地之前的 86×6 观测、15 动作 ONNX 控制器不兼容；不能直接替换旧控制器权重。

四、先运行 MuJoCo
包内已准备独立配置：deploy/deploy_mujoco/configs/g1_walk_3000.yaml。
在部署主机上复制整个 unitree_rl_gym/ 目录，保留 resources/ 和 deploy/models/。
推理和 MuJoCo 不需要安装 Isaac Gym，也不需要训练用的 rsl_rl；需要 PyTorch、numpy、PyYAML、MuJoCo。A10 验证环境为 PyTorch 2.3.1、MuJoCo 3.2.3。
进入复制后的仓库根目录，例如：
cd /workspace/unitree_rl_gym
export PYTHONPATH="$PWD:${PYTHONPATH:-}"
python deploy/deploy_mujoco/deploy_mujoco.py g1_walk_3000.yaml
该配置默认指令为 [0.5,0,0]，可调整 cmd_init。需要图形显示；macOS 的 MuJoCo viewer 通常应通过 mjpython 启动。

本次在 A10 用仓库 scripts/eval_g1_walk_sim2sim.py 的 rollout 做 CPU 无界面验证，测试实际导出的 TorchScript，每组 12 秒：

五、实机部署命令与遥控器流程（本次未执行）
部署主机需要与机器人 DDS 网络相通；<网卡名> 是这台部署主机上连接机器人的网卡，并非 A10 云服务器的网卡。
依赖除 PyTorch/numpy/PyYAML 外还需 unitree_sdk2_python 及其 CycloneDDS 环境。仓库 doc/setup_zh.md 指示克隆 SDK 后 pip install -e .；已有机器人容器时优先复用其 SDK/DDS 环境。
已准备：deploy/deploy_real/configs/g1_walk_3000.yaml。
该配置 policy_path 指向本次导出；max_cmd 从原版 [0.8,0.5,1.57] 改为 [0.8,0.2,0.5]，对应训练横移和偏航范围，其余参数保留原版。
训练前进范围为 0.2–0.8 m/s；零指令已做上述仿真测试，倒退没有训练，也没有本次验证。

在仓库根目录：
cd /workspace/unitree_rl_gym
export PYTHONPATH="$PWD:${PYTHONPATH:-}"
python deploy/deploy_real/deploy_real.py <网卡名> g1_walk_3000.yaml

按仓库 deploy/deploy_real/README.zh.md 和代码：
1. 吊装开机，零力矩状态，L2+R2 进入调试模式。
2. 确认旧 ONNX、遥控速度桥等控制进程已退出，避免并发控制；本程序没有自动释放其他控制器的逻辑。
3. 启动上述程序，收到 lowstate 后持续发送零力矩命令，等待 Start。
4. 按 Start，程序用约 2 秒把双腿、腰和双臂移到配置默认姿态。
5. 脚接地并确认姿态后按 A，开始策略闭环；零摇杆对应零速度指令，策略可能原地踏步。
6. 左摇杆前后控制 vx、左右控制 vy；右摇杆左右控制 yaw_rate。先验证小幅前进，例如 0.2 m/s，避免倒退。
7. Select 或主循环中的 Ctrl+C 退出，程序发送一次阻尼命令。

仓库实机脚本是示例：尚未实现状态陈旧、跌倒倾角、目标跳变等保护；循环周期为推理/通信耗时再 sleep(0.02)，不是严格 50 Hz；启动阶段及任意异常的阻尼退出没有统一 finally 保证。因此实际吊装测试前应核对机器人型号、上肢零位和控制器占用，并按上述代码限制评估现场使用。
